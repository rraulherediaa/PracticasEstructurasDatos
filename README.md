# Microevaluación 2 - Mapas Conceptuales

**Materia:** Estructura de Datos I  
**Tema:** Arreglos, Listas Enlazadas y Ordenamiento

## Descripción
Página web interactiva con mapas conceptuales sobre los temas principales de la Microevaluación 2.

## Contenido
- **Arreglos (Arrays):** Definición, características, operaciones y tipos
- **Listas Enlazadas:** Estructura de nodos, tipos, complejidad y ventajas
- **Algoritmos de Ordenamiento:** Shell Sort y comparación de algoritmos

## Características Interactivas
- Navegación por pestañas entre temas
- Cajas expandibles con información detallada
- Animaciones CSS modernas
- Diseño responsivo (adaptable a móviles)
- Código de ejemplo incluido

## Cómo usar
Abre el archivo `microevaluacion2.html` en cualquier navegador web:
```bash
# Desde terminal (Linux/Mac)
open microevaluacion2.html

# O simplemente haz doble clic en el archivo
```

## Tecnologías
- HTML5
- CSS3 (Flexbox, Grid, Animaciones)
- JavaScript vanilla
