📊 ARREGLOS (Arrays)

Definición

  • Estructura de datos lineal
  • Elementos del mismo tipo
  • Almacenados en posiciones contiguas de memoria
  • Acceso por índice (0 a n-1)
  • Tamaño fijo (en la mayoría de lenguajes)

Características O(1)

  • Acceso directo: arreglo[i]
  • Inserción al final: O(1) amortizado
  • Búsqueda secuencial: O(n)
  • Eliminación requiere desplazamiento: O(n)
  • Uso eficiente de caché CPU

Operaciones Básicas

  • Crear: new int[10]
  • Insertar: append(), push()
  • Buscar: indexOf(), find()
  • Eliminar: pop(), remove()
  • Actualizar: arreglo[i] = valor
// Ejemplo en Python equipos = ["Bolívar", "The Strongest"] equipos.append("Oriente") print(equipos[0]) # Bolívar

Tipos de Arreglos

  • Unidimensionales: Vector [n]
  • Bidimensionales: Matriz [n][m]
  • Multidimensionales: Tensor [n][m][p]
  • Dinámicos: ArrayList, slice
  • Estáticos: Array fijo C/Java
🔗 LISTAS ENLAZADAS

Estructura del Nodo

  • Dato: Información almacenada
  • Siguiente: Referencia al próximo nodo
  • Nodos en memoria dispersa
  • Enlace mediante punteros/referencias
  • Último nodo apunta a null/nil
// Estructura del Nodo class Nodo: def __init__(self, dato): self.dato = dato self.siguiente = None

Tipos de Listas

  • Simple: Un solo enlace (siguiente)
  • Doble: Dos enlaces (siguiente + anterior)
  • Circular: Último apunta al primero
  • Circular Doble: Dobles enlaces + circular
  • Con cabecera: Nodo dummy inicial

Complejidad Temporal

  • Acceso por índice: O(n)
  • Inserción inicio: O(1)
  • Inserción final: O(n) / O(1)*
  • Eliminación conocida: O(1)
  • Búsqueda: O(n)

*O(1) si se mantiene referencia al final

Ventajas vs Desventajas

  • ✅ Tamaño dinámico
  • ✅ Inserción/eliminación eficiente
  • ✅ No requiere reubicación
  • ❌ Mayor uso de memoria (punteros)
  • ❌ Acceso secuencial obligatorio
📈 ALGORITMOS DE ORDENAMIENTO

Shell Sort

  • Mejora del ordenamiento por inserción
  • Compara elementos distantes (gap)
  • Gap inicial: n/2, se reduce hasta 1
  • Complejidad: O(n²) peor caso, O(n log n) mejor
  • In-place: O(1) espacio extra
// Ejemplo en Go func shellSort(arr []int) { gap := len(arr) / 2 for gap > 0 { for i := gap; i < n; i++ { // Inserción con gap } gap /= 2 } }

Clasificación General

  • Por comparación: Quick, Merge, Heap
  • No comparación: Counting, Radix, Bucket
  • Estables: Mantienen orden relativo
  • In-place: O(1) memoria extra
  • Adaptativos: Aprovechan datos parcialmente ordenados

Comparación Algoritmos

  • Bubble: O(n²) - Educativo
  • Insertion: O(n²) - Bueno para pocos datos
  • Quick: O(n log n) - Más usado
  • Merge: O(n log n) - Estable
  • Heap: O(n log n) - In-place

Python vs Go

  • Python: sort() - Timsort O(n log n)
  • Go: sort.Ints() - QuickSort
  • Go: Compilado + rápido
  • Python: Interpretado + flexible
  • Go: Tipado estático
